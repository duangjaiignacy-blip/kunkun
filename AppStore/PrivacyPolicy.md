# Privacy Policy Draft

KUN Translator does not track users and does not sell personal data.

## Data Stored Locally

- Translation history
- Summary notes
- App settings

These are stored locally on the user's Mac. In the App Store build, local files are stored inside the app sandbox container.

## API Keys

AI provider API keys are stored in the macOS Keychain.

## Data Sent to Translation Providers

When the user explicitly triggers a translation or AI enhancement action, the selected text or OCR-recognized text may be sent to the user-configured OpenAI-compatible provider to provide the requested translation or summary.

## Permissions

- Accessibility is used to read selected text after user action.
- Screen Recording is used to capture the user-selected screen area for OCR.
- Network access is used to contact the configured translation provider.

## Tracking

The app does not track users across apps or websites.
