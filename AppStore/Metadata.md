## Description

困困翻译助手是一款 macOS 原生翻译工具，适合阅读网页、文档、聊天消息和技术资料时快速理解内容。

主要功能：

- 翻译记录工作台：自动保存最近翻译，方便回看、复制和整理。
- OCR 截图翻译：框选屏幕区域后识别文字并翻译。
- 文本朗读：支持英语发音偏好和朗读参数调整。
- 音标显示：为英文内容显示音标，辅助学习和复习。
- 总结笔记：把翻译内容整理成可编辑的复习笔记。
- AI 翻译增强：支持 OpenAI-compatible 服务，API Key 保存在系统 Keychain。

隐私与权限：

- 只有在用户主动触发翻译时才读取选中文本或截图区域。
- 翻译历史和笔记保存在本机。
- 不追踪用户，不出售数据，不包含广告 SDK。
